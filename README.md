# ✦ Star Light

### Learn • Practise • Achieve

**Star Light** is a student-friendly learning platform designed for Tamil Nadu State Board Class 12 students.

Our goal is to make exam preparation easier by bringing learning materials, practice questions and solutions together in one place.

---

## 📚 Subjects

Star Light will cover four major subjects:

- 📘 Mathematics
- ⚛️ Physics
- 🧪 Chemistry
- 💻 Computer Science

---

## ✨ Features

- **Chapter-wise Learning** – Explore topics chapter by chapter.
- **Book-back Questions** – Practise textbook exercise questions.
- **Previous-year Questions** – Prepare using verified public examination questions.
- **Important Questions** – Practise selected questions organised by marks.
- **Worked Examples** – Understand solutions through step-by-step explanations.
- **Formula Sheets** – Revise important formulas with explanations.
- **My Bookmarks** – Save questions for quick revision.

---

## 🎯 Our Mission

To make learning simple, organised and accessible for students.

We believe that every student can improve with the right resources, consistent practice and confidence.
